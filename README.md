# Складской бот и дашборд

## Описание проекта
Проект представляет собой комплексное решение для автоматизации складских операций, включающее:
- Телеграм-бота @Warehouse2026Bot для приема и обработки заявок на отгрузку товаров
- Интерактивный дашборд для визуализации статистики заявок

## Цель проекта
Оптимизация процесса обработки заявок на складе, снижение нагрузки на персонал, повышение удобства для клиентов.

## Основные функции

### Телеграм-бот
- Просмотр списка доступных товаров
- Создание заявок на отгрузку
- Отслеживание статуса заявок
- Уведомления об изменении статуса

### Дашборд
- Отображение статистики заявок по статусам
- Список всех заявок с возможностью фильтрации
- Автоматическое обновление каждые 30 секунд

## Установка и запуск

### Требования
- Python 3.8 или выше
- Библиотеки из requirements.txt

### Установка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/username/warehouse-bot-dashboard.git
   ```
2. Перейти в директорию проекта:
   ```bash
   cd warehouse-bot-dashboard
   ```
3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Токен бота уже указан в файле config.py (получен от @BotFather)

### Токен бота
Токен бота уже указан в файле config.py (получен от @BotFather)

## Запуск

### Раздельный запуск (рекомендуется)
В первом терминале запустите бота:
```bash
python bot.py
```
### Во втором терминале запустите дашборд:
```bash
python dashboard.py
```
### Совместный запуск
```bash
python run.py
```
## Использование

### Команды бота
- `/start` - начать работу с ботом
- `/products` - список товаров
- `/order` - создать заявку
- `/status` - статус заявок
- `/dashboard` - ссылка на дашборд
- `/help` - справочная информация

### Навигация по боту
1. После запуска бота нажмите кнопку "Список товаров" для просмотра доступных товаров
2. Нажмите "Создать заявку" для оформления заявки на отгрузку
3. Выберите товар из списка и введите количество
4. Нажмите "Статус заявок" для отслеживания созданных заявок

### Дашборд
Дашборд доступен по адресу http://127.0.0.1:8050 после запуска dashboard.py

На дашборде отображаются:
- График распределения заявок по статусам
- Таблица со всеми заявками (поддерживает фильтрацию и сортировку)

## Структура проекта

- `database.py` - работа с базой данных

  - `warehouse.db` - база данных SQLite (создается автоматически)

## База данных

Проект использует SQLite для хранения данных. База данных создается автоматически при первом запуске и содержит две таблицы:

### Таблица products (товары)
- `id` - идентификатор товара
- `name` - название товара
- `category` - категория
- `quantity` - количество на складе
- `price` - цена

### Таблица orders (заявки)
- `id` - идентификатор заявки
- `user_id` - ID пользователя в Telegram
- `user_name` - имя пользователя
- `product_id` - ID товара
- `quantity` - количество
- `status` - статус (Новая, В обработке, Завершена)
- `created_at` - дата создания
- `updated_at` - дата обновления
